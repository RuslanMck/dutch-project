# skills

claude.ai skills that come with the artifact kit. Each skill is a folder whose `SKILL.md` is both the skill and its description. Replace `<ARTIFACT_URL>` with the learner's own artifact link before uploading.

## Folders

| Folder | Purpose |
|---|---|
| `dutch-exercise-check/` | Checks exercise answers, explains each mistake with its rule number, and logs mistakes in the artifact. |
