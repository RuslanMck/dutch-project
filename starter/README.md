# starter

Seed data for a new artifact, imported with the ArtifactData tool during setup (see the root `README.md`). Each item's `id` becomes the document id; the other fields become the document. The keys (`nl`, `uk`, `art`, `ex`, …) are the artifact's legacy field names, so they change only together with `artifact/dutch-materials.html`.

## Files

| File | What it does |
|---|---|
| `words.json` | Starter dictionary: about 530 Dutch words and phrases with Ukrainian translations, grouped by topic. Goes to the `words` collection. |
| `rules.json` | Seven grammar rules explained in Ukrainian (articles, pronouns, modal verbs, plurals, adjectives…). Goes to the `rules` collection. |
