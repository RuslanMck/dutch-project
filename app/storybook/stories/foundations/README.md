# foundations

Token pages. They read `tokens/tokens.json` directly, so they never need editing when a value changes.

## Files

| File | What it does |
|---|---|
| `Foundations.stories.js` | Colours (Сад and app today), typography, font weights, radius, spacing and shadows. |
| `Icons.stories.js` | Every icon the app uses and the icon rules (grid, stroke, sizes, states). |
