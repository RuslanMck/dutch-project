# sketches

Concept screens in the Сад look that are not built yet. Each renders in a shadow root so its own CSS stays separate from `garden.css`. When a sketched part gets built, it becomes a component story.

## Files

| File | What it does |
|---|---|
| `shadow-frame.js` | Renders markup with its own stylesheet inside a shadow root. |
