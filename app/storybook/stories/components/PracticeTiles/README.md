The 2×2 practice tiles on Головна, one soft colour per kind of practice: Картки `garden-periwinkle`, Порядок слів `garden-sand`, Фрази `garden-peach`, Важкі слова `garden-blush`. Each has a white icon disc, a name and a count line in `garden-ink`.

Cartки, Порядок слів and Фрази open their tab (`data-tab`); Важкі слова starts the struggling-words drill.

Accessibility: each tile is one button; its text is its name.

Markup from `public/index.html`; styled by `storybook/styles/garden.css`.
