# components

One folder per UI component of the app. Each holds `<Name>.stories.js` (the stories) and `README.md` (the guidelines shown on its Docs page). Folder and file names are PascalCase, the Storybook convention.

## How to add a component

Copy the template from the `storybook-maintenance` skill (`references/story-template.md`) into a new `<Name>/` folder, use the app's real markup, and add a row here.
