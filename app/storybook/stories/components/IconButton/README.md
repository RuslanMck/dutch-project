A 44px transparent button holding one 22px line icon in `garden-ink-soft`.

- Always pass an `aria-label` in Ukrainian.
- Toggle icons (`.shuffle-button`) use `aria-pressed`; pressed turns the icon `garden-ink` on a `garden-sand` pill.
- `.del` is the inline row delete (`tap-compact`); first tap adds `.armed`, which shows "Видалити?" in `garden-wrong`, second tap deletes.

Markup from `public/index.html`; styled by `storybook/styles/garden.css`.
