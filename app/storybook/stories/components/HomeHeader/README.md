The gold header of Головна: the Dutch greeting, a subtitle, and the search field that overlaps it. Typing and Enter opens Слова with the query.

- `.home-header` — gradient from `garden-primary` to `garden-sand`, `garden-radius-lg` bottom corners, `garden-ink` text.
- `.home-search` — `garden-raised`, `garden-radius`, `garden-shadow`; the focus ring goes on the whole field.

Only on Головна; every other tab shows the plain page title.

Accessibility: the search has a visually hidden label and `role="search"`.

Markup from `public/index.html`; styled by `storybook/styles/garden.css`.
