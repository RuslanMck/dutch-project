# .storybook

Storybook configuration. No stories or styles here.

## Files

| File | What it does |
|---|---|
| `main.js` | Framework (`@storybook/html-vite`), where stories live, addons, the app's `public/fonts` served at `/fonts`, telemetry off. |
| `preview.js` | Loads `tokens.css`, `garden.css` and `stories.css` into every story; backgrounds, sidebar order, autodocs. |

See the `storybook-maintenance` skill for the rules.
