# public

Browser code and static files of the web app, served by Express without a build step. Only browser modules live here; they never import from `src/`. UI text is Ukrainian.

## Files

| File | What it does |
|---|---|
| `index.html` | The app page: header, tab navigation, the static shells of the six tabs (table, cards, practice, rules, phrases, texts), the practice mode select (FSRS, article, «Важкі слова») with its "i" hint, the FSRS summary's «Потренувати важкі слова (N)» button, the custom drill's note and end block («Готово! …», «Ще раз», «Назад»), the round summary's drill buttons («Повторити важкі (n)», «Важкі й середні (n)»), and the one delete confirmation dialog. |
| `login.html` | The password sign-in page shown before the session cookie exists. |
| `app.js` | UI controller: loads the collections, renders every tab (the words table has no error or status columns), runs the FSRS translation practice session (batch, grades, summary; one session per Amsterdam calendar day, kept in sessionStorage). Each set is practised in two rounds: round 1 UA → NL (`gradeTranslationAnswer`), round 2 NL → UA (`gradeReverseTranslationAnswer`, with «Я мав рацію» holding the grade until pressed or «Далі»); the phrase cards use the same rounds without typing. When the queue runs out it asks the batch again with the same session: new words continue the session, otherwise the summary shows, which can post extra New words. The summary also reads the struggling-words count (`GET /api/practice/struggling-words`) and shows the drill button when it is above zero. The custom drill (`startCustomDrill({ title, words, returnTo })`, section 3b) is practice without a schedule: round 1 UA → NL and round 2 NL → UA over the same words, checked with the daily practice's grading functions, with «Я мав рацію» in round 2; a word comes back until it is right; the end shows the first-check counts per direction. It is started by the struggling-words button («Важкі слова», read from `GET /api/practice/struggling-words`) and by the round summary's buttons (words from `GET /api/practice/drill-words`, `returnTo: 'round-summary'`). It posts nothing; a test checks section 3b for grading calls. `returnTo` is 'round-summary', 'practice' or 'decks' (or `{ name, onBack }`); «Назад» goes there. The article drill, the cards (today's word batch read-only; the phrase deck asks the phrase batch again at its end), the shared word delete dialog, keeps user input across re-renders and binds events. |
| `api.js` | REST client (same-origin cookie, a 401 goes to `/login`), the practice calls (word and phrase batches, grades, stats, the round summary, the struggling-words list, the drill words `getDrillWords(ids)`) and the live-update subscription to `/api/events`. |
| `logic.js` | Pure helpers with no DOM access: HTML escaping, answer checking for the article drill (`checkAnswer`), FSRS translation grading (`gradeTranslationAnswer`: `good`, `hard`, `again`; the article never changes the grade, a missing or wrong de/het is named in the message; `revealTranslationAnswer` for «Не знаю»), on answers made comparable by `normalizeAnswerText` (case, typographic quotes, punctuation, spaces) with Levenshtein distance, the Ukrainian day plural and the next-review line, short dates for the words table, rule-body rendering, and the custom drill (`planCustomDrill` for the two rounds, `advanceDrillQueue` for the queue order, `formatCustomDrillProgress` for the progress line, `buildCustomDrillEnd` for the end text, `buildRoundDrillButtons` for the round summary's buttons, `formatStrugglingDrillButton` for the summary button; no network, no grading), and the two-way practice rounds (`gradeReverseTranslationAnswer` and `revealReverseTranslationAnswer` for round 2, `splitIntoRounds` and `planNextRound` for the waiting cards per direction, `orderNextRound` so a word never comes straight back, `formatRoundProgress` and `formatRoundStart` for the round lines, `answerKey` for the answered set). |
| `app.css` | Styles for the app and login pages in the Сад look (light only). Generated from `storybook/` (`npm run app-css` there) — do not edit by hand. |
| `icon.svg` | App icon, used as the favicon and in the web manifest. |
| `manifest.webmanifest` | Web app manifest, so the page can be installed on a phone home screen. |

The «Порядок слів» tab (after «Фрази») is a Duolingo-style word-order exercise: the learner taps the shuffled Dutch words of a Ukrainian sentence into the answer line, checks it, and manages the stored sentences (generate, `.md` import, list with delete); its pure state and formatting helpers live in `logic.js`, its REST calls in `api.js`. A rule dropdown above the exercise (`RULE_LABELS`, `formatRuleFilterSummary`, `buildRulesQuery`, `parseStoredRules` for the choice kept in localStorage `wordOrderRules`) filters the set; after «Перевірити» the sentence's schema is shown as boxes coloured by `roleColourClass` (`formatStructureLine` for the text line). Sentences can have several accepted word orders (spec §9): `formatExpectedFormLabel` gives the muted line under the Ukrainian sentence naming the word order it expects («Форма: Інверсія»), `buildWordOrderCheckView` gives the feedback (`message`, `tone`, the «Основний варіант» line when the learner found an alternative, the other orders when wrong), and `buildAlsoOrderLines` gives the «також: …» lines in the sentences list.

The «Колоди» tab (after «Практика», section 7 of `app.js`, markup `#tab-decks` in `index.html`) builds named word lists for extra drilling. Three views: the deck list (create, practise, change, delete with `askConfirm`), the word picker («Обери слова») with search, filter chips (Усі, Важкі, Середні, Легкі, Нові, Обрані), a sort select and a sticky bar («Обрано: N», «Додати слова»), and the confirmation form (name, description, the chosen words with ×, «Назад»). The picker builds its rows once per catalog load (`GET /api/decks/word-catalog`) and filters by toggling `hidden`; the deck calls are in `api.js` (`listDecks`, `getDeck`, `createDeck`, `updateDeck`, `deleteDeck`, `getDeckWordCatalog`). «Практикувати» fetches the deck's words (`getDeck`, then `getDrillWords`) and starts `startCustomDrill({ title: 'Колода: …', returnTo: 'decks' })`. Live `decks` changes refetch the list; `words` changes refetch an open picker's catalog. The pure helpers in `logic.js` are `filterCatalog`, `sortCatalog`, `foldSearchText` (search ignores case and accents), `formatLastPracticed`, `formatDeckWordCount` (Ukrainian plurals), and the selection model (`toggleSelected`, `selectVisible`, `clearSelected`). The section uses `textContent` only.
